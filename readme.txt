Restaurant Budget Optimizer

Приложение для расчёта стоимости блюд в ресторанах с оптимизацией по бюджету.

Функции:
- Ввод бюджета (например, 5000 тенге)
- Подбор комбинации: первое + второе + напиток
- Учёт услуги (10%) + чаевые (5%)
- Не превышает бюджет
- Сравнение цен в разных ресторанах

Технологии:
- Frontend: React
- Backend: Node.js
- Deploy: Railway
